# توصيات أمان تطبيق الهاتف المحمول (Mobile Application Security Recommendations)
**النظام المستهدف:** تطبيق الهواتف الذكية للفنيين والمشتركين (Flutter)  
**المعايير المعتمدة:** OWASP Mobile Application Security (MASVS)  

---

## 1. تشفير البيانات المحلية والتخزين الآمن (Secure Local Storage)

### أ. تشفير قاعدة بيانات Isar
الوضع الحالي لقاعدة البيانات في `isar_service.dart` يفتح الملفات بنص واضح. لتأمين البيانات، يجب تعديل التهيئة لتطبيق مفتاح تشفير متماثل:
1. توليد مفتاح تشفير بحجم 256-بت وحفظه في مساحة تخزين آمنة.
2. استخدام المفتاح المشفر لفتح قاعدة البيانات.

### ب. تشفير التوكن في مساحة النظام الآمنة
تطبيق الهاتف يستخدم بالفعل `FlutterSecureStorage` في `api_client.dart` لحفظ رمز الـ JWT (`jwt_token`). 
- **التوصية:** هذا سلوك ممتاز وآمن. يجب فقط التأكد من إعداد حماية إضافية على نظام الأندرويد لتعطيل ميزة النسخ الاحتياطي التلقائي للتطبيق (`allowBackup="false"` في `AndroidManifest.xml`) لكي لا تسرب ملفات الـ Secure Storage عند عمل نسخة احتياطية من الهاتف للكمبيوتر.

## 2. حماية التطبيق ضد الهندسة العكسية والتلاعب (Anti-Reverse Engineering)

### أ. تمويه الأكواد والرموز (Code Obfuscation)
عند تصدير حزمة التطبيق النهائية (Production APK/IPA)، يجب تفعيل ميزة التمويه لحماية أسماء الفئات والوظائف البرمجية من استخراجها وقراءتها بوضوح:
```bash
flutter build apk --obfuscate --split-debug-info=/<directory>
```

### ب. التحقق من سلامة البيئة والتجذير (Root & Jailbreak Detection)
الفنيون الميدانيون يمكنهم التلاعب بموقع الـ GPS أو قراءة البيانات الحساسة إذا كانت أجهزتهم تحتوي على صلاحيات الروت (Rooted Android / Jailbroken iOS).
- **التوصية:** دمج مكتبة مثل `flutter_jailbreak_detection` للتحقق من سلامة بيئة النظام عند فتح التطبيق، وإغلاقه فوراً مع إرسال بلاغ للسيرفر إذا تبين أن الهاتف مكسور الحماية.

## 3. تأمين الاتصالات وتثبيت شهادات الـ SSL (SSL Pinning)

### منع هجمات اعتراض اتصالات الشبكة (Man-in-the-Middle - MITM)
بشكل افتراضي، يثق تطبيق الموبايل بأي شهادة معتمدة من نظام التشغيل. إذا قام مهاجم بتثبيت شهادة مخصصة على هاتف الفني، فإنه يستطيع قراءة وتعديل كافة البيانات (مثل إرسال قراءات أو مدفوعات وهمية).
- **التوصية:** تفعيل **SSL Pinning** في حزمة `Dio` لتقييد اتصالات التطبيق بالشهادة الرقمية الخاصة بسيرفر الباكيند حصرياً، ورفض أي اتصال يتم اعتراضه.
- *مثال للتطبيق في Dio:*
  ```dart
  import 'dart:io';
  // استخدام مكتبة لربط شهادة السيرفر
  (dio.httpClientAdapter as IOHttpClientAdapter).createHttpClient = () {
    SecurityContext context = SecurityContext(withTrustedRoots: false);
    // تحميل شهادة السيرفر الرسمية فقط
    context.setTrustedCertificatesBytes(serverCertificateBytes);
    return HttpClient(context: context);
  };
  ```
