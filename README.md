# نظام إدارة الكهرباء الذكي (Smart Electricity Management System - SEMS)

نظام متكامل ومتقدم لإدارة قطاع الكهرباء يغطي كافة الاحتياجات من الفوترة والمراقبة والذكاء الاصطناعي إلى إدارة الفنيين في الميدان. تم تصميم هذا النظام ليكون متيناً وآمناً ومستعداً للعمل في بيئة الإنتاج الحقيقية.

---

## 📋 نظرة عامة على هيكل المشروع

يحتوي المشروع على أربعة أقسام رئيسية تعمل معاً بتناغم تام:

1. **`backend_api/`**: الواجهة الخلفية المركزية (Node.js & Express). تقوم بربط قواعد البيانات وتوفير البيانات للتطبيقات الأخرى.
2. **`admin_dashboard/`**: لوحة تحكم الإدارة الشاملة (Next.js & Tailwind). تتيح للمدراء مراقبة النظام والرسوم البيانية وتتبع الفنيين.
3. **`mobile_app/`**: تطبيق الموبايل للفنيين (Flutter). يستخدم لقراءة العدادات ورفع الإحداثيات وتوثيق القراءات بالصور.
4. **`ai_service/`**: خدمة الذكاء الاصطناعي (Python & FastAPI). تقوم بتحليل البيانات لاكتشاف التلاعب، توقع الاستهلاك، قراءة العدادات بالصور (OCR)، وتقديم النصائح عبر الشات بوت.

كما يحتوي المشروع على مجلدات الدعم التالية:
- **`monitoring/`**: إعدادات المراقبة (Prometheus).
- **`scripts/`**: أدوات التشغيل والصيانة (مثل سكريبت النسخ الاحتياطي لقاعدة البيانات).
- **`.github/`**: خطوط الـ CI/CD للتكامل والنشر المستمر.

## 🚀 كيفية تشغيل النظام بالكامل (الإنتاج)

تم تجهيز النظام للعمل عبر حاويات دوكر (Docker) لضمان بيئة موحدة وسريعة.

### المتطلبات المسبقة:
- تثبيت [Docker](https://www.docker.com/) و [Docker Compose](https://docs.docker.com/compose/).

### خطوات التشغيل:
1. افتح موجه الأوامر (Terminal/CMD) وانتقل إلى مجلد المشروع الرئيسي.
2. قم بتشغيل الأمر التالي:
   ```bash
   docker-compose up -d --build
   ```
3. سيقوم Docker بتنزيل المتطلبات وتشغيل كافة الأنظمة:
   - قاعدة البيانات (PostgreSQL) ستعمل على المنفذ `5432`.
   - الواجهة الخلفية (Backend) ستعمل على المنفذ `3001`.
   - لوحة تحكم المدراء (Dashboard) ستعمل على المنفذ `3000`.
   - خدمة الذكاء الاصطناعي (AI Service) ستعمل على المنفذ `8000`.
   - نظام المراقبة (Grafana) سيعمل على المنفذ `3005`.

## 🛠️ تفاصيل التطوير (للمبرمجين)

### 1. واجهة برمجة التطبيقات (Backend API)
- **التقنيات:** Node.js, Express, Sequelize ORM.
- **التشغيل اليدوي:** `npm install` ثم `npm start`.
- **الأمان:** محمي بـ JWT, Helmet, Rate Limit, XSS Protection.

### 2. لوحة التحكم (Admin Dashboard)
- **التقنيات:** Next.js (App Router), TailwindCSS, Recharts, TypeScript.
- **التشغيل اليدوي:** `npm install` ثم `npm run dev`.
- تتميز بتصميم داكن حديث (Glassmorphism).

### 3. تطبيق الموبايل (Mobile App)
- **التقنيات:** Flutter.
- **التشغيل اليدوي:** `flutter pub get` ثم `flutter run`.
- يحتوي على ميزات الـ GPS والتصوير الفوري (Camera) دون السماح باختيار صور قديمة منعاً للتلاعب.

### 4. الذكاء الاصطناعي (AI Service)
- **التقنيات:** Python, FastAPI, OpenCV, Tesseract, Scikit-Learn.
- **التشغيل اليدوي:** 
  ```bash
  python -m venv venv
  .\venv\Scripts\activate
  pip install -r requirements.txt
  uvicorn main:app --reload
  ```

## 🔒 الأمان والنسخ الاحتياطي

- **قاعدة البيانات:** يتم تخزين البيانات بشكل آمن، ويتوفر نص برمجي في `scripts/backup_db.sh` يمكن جدولته (Cron Job) لأخذ نسخ احتياطية تلقائياً.
- **تشفير البيانات:** جميع كلمات المرور مشفرة باستخدام `bcrypt`، وتتواصل الأنظمة عبر توكنات `JWT`.
- **خطوط الإنتاج:** تم إعداد ملفات في مجلد `.github/` لإجراء عمليات الاختبار والبناء تلقائياً عند دفع (Push) الكود المصدري لمنصة GitHub.
